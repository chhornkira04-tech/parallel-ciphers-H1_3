# Challenge StarterKit

Содержит клиента к API платформы соревнований и пример его использования для получения заданий и отправки ответов.

Клиент находится в библиотеке `Challenge` и подключается в приложении `ConsoleApp`. Запусти приложение `ConsoleApp`, чтобы увидеть как все работает.
Для своих потребностей можешь модифицировать `ConsoleApp`, либо создать отдельное приложение и подключить к нему проект `Challenge`.

## Решатели
В `ConsoleApp/Solvers/` есть решатели для `moment`, `math`, `determinant`, `cypher`, `polynomial-root`, `steganography`, `starter`. `SolverRegistry` подхватывает C#-реализации `ITaskSolver` и при наличии `python_solvers/<type>.py` подключает их через `PythonBridgeSolver`.

## Инфраструктура
В `ConsoleApp/Infra/` добавлены `ITaskApi`, `RunOptions`, `RunLog`, `SecretProvider`.

## Как работает
1. Получить раунд → 2. Взять задачу `AskNewTaskAsync` (запускает таймер) → 3. `Solver.TrySolve` решает автоматически или ввод вручную → 4. `CheckTaskAnswerAsync` отправляет ответ. При неверном ответе/ошибке программа останавливается.

## Защита вычислений
Все C#-проекты, в том числе новые, наследуют `CheckForOverflowUnderflow=true` из
`Directory.Build.props`; сборка отклоняет отключение этой настройки. Явный `unchecked`
запрещен тестом синтаксиса C# в CI. Тесты запускаются командой:

```sh
dotnet test Tests/Tests.csproj --configuration Release
```

Вызывайте новые решатели через `SolverRegistry.TrySolve` (или `Solver.TrySolve`).
Реестр перехватывает ошибки арифметики, формата и неподдерживаемого ввода даже у
прямых реализаций `ITaskSolver`, очищает ответ при отказе и отклоняет пустые ответы,
NaN и бесконечность в числовом ответе. Лимит вопроса — 65536 символов.
При отказе текущий интерфейс предлагает ручной ответ; автоматический ответ не отправляется.

`math` теперь отклоняет переполнение int, включая промежуточные операции.
Парсеры ограничивают глубину выражений значением 128. Для многочленов установлены
ограничения 4096 символов и степень 128, проверяются конечность вычислений и невязка
корня. Определитель использует BigInteger и ограничение матрицы 128×128.

Эта защита не доказывает правильность алгоритма: double/float не бросают исключение
при переполнении, а конечный ответ может скрыть неконечный промежуточный результат.
Новые численные решатели обязаны проверять промежуточные значения через IsFinite
и иметь граничные тесты. Проверяемая арифметика не изменяет уже скомпилированные
внешние библиотеки. Общего принудительного тайм-аута и ограничения памяти для C#
пока нет; такие гарантии требуют запуска решателя в отдельном процессе.


## Секрет команды

Не вставляй секрет команды непосредственно в исходный код и не публикуй его в Git.
Перед запуском задай переменную окружения `TEAM_SECRET` либо создай локальный файл
`secrets.json` в корне проекта со следующим содержимым:

```json
{
  "teamSecret": "ВСТАВЬ_СЮДА_СЕКРЕТ_КОМАНДЫ"
}
```

Файл `secrets.json` добавлен в `.gitignore` и не должен попадать в коммиты.
Если секрет уже попадал в публичный репозиторий, сначала отзови его и создай новый.
